# C Sharp Exercises Repository

In this repository I put exercises about solving programming problems by myself without using help from LLMs, this repository is meant to show my skills in solving complex and analitical algoritms, while also showing my knowlegde in the .NET Framework (C#)

The repository was created in .NET 10


## Structure
The structure of the repository is divided by folders with different types of problems, currently the folders in the project are the following:

root/<br>
├── README.md<br>
├── .gitignore<br>
├── EjerciciosCSharp.sln<br>
├── Arrays/<br>
├── Basic/<br>
└── DataStructures/<br>

## Download and use
To view the repository, you can clone the repository in local with the comand:<br>
```git clone https://github.com/JuanfeP2004/CSharp-Exercises.git```

Later in visual studio or visual studio code you have to build the solution, remember that in visual studio code you have to install the **C# Dev Kit Extention**

To start you have to build the repository, use the command:<br>
```dotnet build EjerciciosCSharp.sln```

When all is configurated, you can run the project in each folder using:<br>
```dotnet run```
